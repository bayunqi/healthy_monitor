# HealthyMonitor

**A quiet coach for your back. Built for the Mac you sit in front of all day.**

You write code. You forget to stand. Your back remembers.

HealthyMonitor lives in your menu bar and gently nudges you to stand, drink, and stretch — not on a fixed schedule, but on one that adapts to how you actually work. A built-in LLM coach learns your pain points, your meetings, your patterns, and adjusts. Over weeks, your pain score should trend down. That is the only number that matters.

---

## Designed for the way you actually work.

**Always there. Never in the way.**
A single icon in the menu bar. One click for what's next. One keystroke to confirm. No dock icon, no window stealing focus, no buzz during a deep-focus block.

**Reminders that learn.**
Stand, water, stretch — each with its own cadence. Skip too often, and the schedule eases. Build a streak, and it holds steady. Your quiet hours are sacred.

**A coach, not a nag.**
A weekly conversation with an LLM that already knows your profile: where it hurts, when you sit longest, what's worked. No guilt. No lectures. Just the next small thing to try.

**Compliance you can see.**
Open the menu bar to a clean ring for each reminder type. Green when you're on track. No graphs that demand interpretation.

---

## Privacy. Built in, not bolted on.

Your health profile lives on your device and your own iCloud — end-to-end encrypted, never on our servers, because we don't have servers. The only data that leaves your Mac is the conversation text you choose to send to the LLM, over HTTPS, without device identifiers. Your DeepSeek API key sits in the macOS Keychain. Nowhere else.

No analytics. No telemetry. No accounts.

## How it's built.

| Layer | Choice |
|---|---|
| UI | SwiftUI 6, native on every target |
| Shared logic | `HealthyMonitorCore` — one Swift Package, three platforms |
| Storage | JSON on disk today. Swift Data + CloudKit in Phase 2. |
| LLM | DeepSeek (`deepseek-chat`) — OpenAI-compatible, low cost, China-accessible, automatic prompt caching |
| Notifications | `UNUserNotificationCenter`, local only |
| Future sync | `WatchConnectivity` for the wrist |

The macOS app is the authoritative scheduler. It's always running, so reminders are reliable. iOS and watchOS join in Phase 2.

For the full reasoning behind each choice, see [`DECISIONS.md`](DECISIONS.md). The codebase contract for any new contributor (human or AI) is [`CLAUDE.md`](CLAUDE.md).

## Get started.

**Requirements**
- macOS 14 or later
- Xcode 16 or later
- A DeepSeek API key from [platform.deepseek.com](https://platform.deepseek.com)

**Build and run**

```bash
git clone git@github.com:bayunqi/healthy_monitor.git
cd healthy_monitor
open HealthyMonitorMac.xcodeproj
```

In Xcode, select your Apple ID under **Signing & Capabilities → Team**, choose **My Mac** as the run destination, and press ⌘R. The app launches into your menu bar. Open **Settings** and paste your DeepSeek API key.

**Run the tests**

```bash
xcodebuild test -scheme HealthyMonitorCore -destination "platform=macOS"
```

**Regenerate the Xcode project**

The project is described in `project.yml` and generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
xcodegen generate
```
